# dsh-session-opentool

给 DeepSeek Harness 的侧栏会话「⋯」菜单加两行，**直接用系统文件管理器打开这个会话在本地磁盘上的文件夹**。

| 菜单行 | 打开什么 |
| --- | --- |
| 打开所在文件夹 | 会话的工作目录 `header.cwd`，也就是 Agent 读写文件的目录，左侧栏工作区对应的那个路径 |
| 打开会话记录位置 | 会话日志 `session.v4.jsonl.zstd` 所在的目录，形如 `<DSH_HOME>/sessions/--<cwd 编码>--/<sessionId>/` |

## 边界

- 纯只读操作，不改任何文件、不动会话记录、不碰工作区登记。
- 会话正在运行也能打开（没有副作用）。
- 目录被改名或删除后，会话记录仍指向旧路径，此时会提示目录不存在，并带上完整路径。
